# Black Friday Deal Guide 2026

A one-page guide to Black Friday 2026 deals. Each deal is scored against its usual selling price, not the banner. The live site runs on GitHub Pages from `index.html`.

Prices were checked on Nov 26, 2026 and change fast. Recheck before buying.

**My list:** press Add on a deal, pick who it's for, then open My list and copy the prompt. The names you add stay in your browser.
